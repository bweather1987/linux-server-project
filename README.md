# Linux Server Monitoring Script

## Overview

A Python-based server monitoring script built in a Linux environment. The script checks system resources and verifies that the Nginx web server is running.

## What It Monitors

- Disk usage
- Memory usage
- Nginx service status

## Technologies Used

- Linux / Ubuntu
- Python 3
- Nginx
- Git
- GitHub
- UFW Firewall

## How It Works

The script collects information from the Linux system, calculates resource usage, and checks whether resource usage exceeds defined thresholds.

If disk or memory usage exceeds 80%, the script displays a warning.

The script also checks whether Nginx is active and reports its status.
